# Uhired AI — PC demo

Clickable prototype of the Uhired AI desktop flow, built from the Figma "PC" page:

- Landing → **Start now** → chat bot: upload resume (02), reading (03), results pinned above the message box (04b), practice set panel (05), new bot (07/08)
- AI mock interview: ready + mic check (M01), live answer with faint hints (M02), pause (M02c), 30-second free preview paywall (M10), Pro activated (M11), final results + advice (M12)
- Mock history: result card + pinned chip in chat (H01), history side panel (H02)

Use the round menu button on the left edge to jump to any screen, or open a screen directly with a hash, e.g. `#m01`, `#h02`.
